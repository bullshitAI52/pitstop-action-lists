# Enfocus PitStop PDF 动作列表

这里归档用户提供的 `动作.rar` 及其中解压出的 11 个 `.eal` 动作列表。

这些文件用于 **Enfocus PitStop Pro**，配合 **Adobe Acrobat Standard/Pro/DC** 处理 PDF，适合工程图纸、扫描图纸和印前文件。`.eal` 是 PitStop 的 Action List 格式，不是 AutoCAD 插件，也不是 Photoshop 动作文件。

## 主要功能

| 文件 | 作用 |
| --- | --- |
| `A00 转换注释对象为普通对象.eal` | 将 PDF 注释对象转换为普通对象 |
| `A01 一键解除图章签名无效错误.eal` | 处理图章/签名无效相关对象 |
| `A02 一键专蓝蓝色+去底色漂白.eal` | 转蓝并尝试去除底色 |
| `A03 一键转蓝图保留（图片红章）.eal` | 转蓝并保留图片红章 |
| `A04 一键转全部转蓝图.eal` | 将全部内容转为蓝图效果，可在动作中调整颜色 |
| `A05 一键转蓝保留（矢量红章）.eal` | 转蓝并保留矢量红章 |
| `A06 一键扫描件背景漂白.eal` | 扫描件背景漂白 |
| `A07 一键文本扫描件去除底色.eal` | 文本扫描件去底色，可重复运行 |
| `A08 一键蓝图保留红章（图片红章）3.9.eal` | 3.9 版本的图片红章保留动作 |
| `A09 一键变黑白.eal` | 将 PDF 内容处理为黑白效果 |
| `A10 修改最小线条宽度.eal` | 调整 PDF 最小线条宽度，动作内可修改参数 |

文件名中的“红章”通常指 PDF 中的印章图像或矢量对象；实际保留效果取决于 PDF 的对象结构、颜色空间和动作参数。

## 使用前提

需要安装并激活：

1. Adobe Acrobat Standard、Pro 或 DC；
2. Enfocus PitStop Pro 插件。

Adobe Acrobat Reader 不能运行这些动作。单独安装 Acrobat 也不能提供 Action List 功能，必须有 PitStop Pro。也可以在 Enfocus PitStop Server 中导入并用于自动化流程。

## 导入和运行

### PitStop Pro

1. 用 Acrobat 打开待处理的 PDF，建议先复制一份备份。
2. 打开 `PitStop Pro → Action Lists`（不同版本菜单名称可能略有区别）。
3. 在 Action Lists 面板的菜单中选择导入/Import。
4. 选择本仓库的 `.eal` 文件。
5. 选中动作并运行，先检查预览或输出结果。
6. 确认效果后再保存 PDF 或另存为新文件。

也可以直接使用仓库根目录的 `动作.rar`，解压后再导入动作文件。仓库中的 `actions/` 文件夹是已经解压好的副本，便于直接选择。

### 修改颜色或线宽

部分文件名提示“双击进去可以改色值”或“自定义线宽”。导入后先复制动作，再编辑副本中的参数，避免覆盖原始动作。不同 PitStop 版本的参数界面可能不同。

## 安全与兼容性说明

- 本仓库只做文件归档和说明，没有运行 `.eal` 文件，也没有验证其对实际 PDF 的处理结果。
- 动作会修改 PDF 对象，使用前务必保留原始文件。
- `A01` 涉及签名/图章对象；处理后可能影响 PDF 的认证状态、审阅记录或后续签名验证，请先在副本上测试。
- 这些动作可能依赖特定版本的 PitStop、颜色配置和 PDF 对象结构；未保证在所有版本中效果一致。
- `动作.rar` 及动作文件未附独立许可证。本仓库不擅自授予 MIT 等开源许可；使用和再分发请确认原作者及相关权利人的许可。
